# O que é o AutoCards

**O AutoCards é um add-on do Anki que cria flashcards novos para você todo dia, com IA, sozinho.**

Você configura um ou mais **geradores**. Cada gerador é uma receita: o que você quer estudar, como os cards devem ser escritos, o formato, se tem áudio e algumas regras. Quando você abre o Anki, cada gerador cria a cota do dia em segundo plano e mostra um aviso curto ao terminar.

## Por que existe

A maioria dos add-ons de IA para o Anki cria cards **quando você pede**. O AutoCards foi feito para um hábito diário:

| | |
|---|---|
| **Roda sozinho** | Uma vez por dia por gerador, quando o perfil abre. Se o Anki ficar aberto de um dia para o outro, ele confere de novo a cada hora. Dias perdidos não se acumulam. |
| **Protege suas revisões** | Freia quando as revisões atrasadas se acumulam, pode aumentar a quantidade aos poucos e tem um teto de gasto mensal. |
| **Prompt editável** | O prompt é dividido em campos (papel da IA, tema, nível, frente, verso, o que evitar, exemplos) que você liga, desliga, reordena e amplia, com prévia ao vivo. |
| **Áudio à sua escolha** | Vozes grátis do Microsoft Edge, OpenAI ou ElevenLabs. |
| **Qualidade que dá para medir** | Toda execução e todo card ficam registrados: prompt, modelo, tokens, custo estimado e o que você aceitou, editou ou descartou. |

## Do que você precisa

- **Anki 26.09 ou mais novo**, no Windows, macOS ou Linux.
- **Um serviço de IA.** Qualquer serviço no formato de chat da OpenAI funciona: OpenAI, OpenRouter, Groq, ou um modelo no seu próprio computador com Ollama ou LM Studio.

Mais nada: o AutoCards usa só o que já vem com o Anki. Não há pacotes Python nem linha de comando.

:::note
A geração acontece no computador. Os cards criados lá sincronizam com o AnkiDroid e o AnkiMobile normalmente.
:::
